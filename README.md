# Etch-a-Sketch

A simple web-based Etch-a-Sketch drawing application built with HTML, CSS, and JavaScript.

## Description

This project recreates the classic Etch-a-Sketch toy in a web browser. Users can draw by hovering over a grid of cells, which change color to create artwork. The grid size can be customized to allow for different levels of detail.

## Features

- Interactive drawing grid
- Customizable grid size (1-100 cells per side)
- Responsive design
- Clean, modern interface

## How to Use

1. Open `index.html` in your web browser
2. Hover your mouse over the grid to draw (cells will turn black)
3. Click the "Change Grid Size" button to adjust the grid resolution
4. Enter a number between 1 and 100 when prompted
